# 董事会决议（抵质押担保类）

江阴利泰装饰材料有限公司（以下简称本公司）于2016年12月25日  
在公司会议室（地点）召开董事会同意以下事项并形成本决议：

1、同意本公司以本公司所有的以下资产为江阴东华铝材科技有限公司对中国银行股份有限公司江阴支行（或其下属分支机构）贰仟万 元授信额度债务及其相应的利息、罚息、违约金、应付费用等提供抵押、（或质押）担保，直至前述债务全部清偿完毕。

- A、澄土国用（2008）第 3884 号项下 20879.3 平方米土地使用权
- B、澄土国用（2008）第 3885 号项下 10881 平方米土地使用权
- C、房权证澄字第 fhs0002840 号项下 27645.04 平方米房产

2、本公司授权 签署相关的担保合同等法律文件及办理抵押（或质押）登记手续。

3、其他事项：

本公司同时确认：

1、本决议是按照本公司章程中董事会召集程序、表决方式、表决人数等相关规定所召开的。

2、本决议上所有董事签字为其真实签字。
